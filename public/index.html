Install the extension in each Chrome profile

  1. Click Open Extensions on a profile below. Its Extensions page opens, and the folder path is copied.
  2. Turn on Developer mode (top right), then click Load unpacked.
  3. In the folder picker, press ⌘⇧G, then ⌘V, Return, and click Select.

Profiles tick themselves off once Chrome has the extension loaded.
